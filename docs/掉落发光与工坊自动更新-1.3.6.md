# 掉落发光与工坊自动更新 1.3.6

日期：2026-10-13（Asia/Shanghai）。本次只修改服务器插件，不编辑地图源码、神器技能脚本、权限名单或资源包。

## 神器枪偶尔不发光

旧逻辑把“已经保存原始发光状态”误当成“当前仍在发光”，第一次设置后不再检查。引擎在丢弃、物理落地或后续更新中清除发光参数时，旧逻辑一直跳过，诊断里的发光数量也只数快照，没有读取实际状态。

- 每 0.1 秒核对掉落地图枪的真实 glow 字段；发现关闭、类型/阵营/距离/颜色或时长被改写，重新设置并标记网络状态。
- 状态正常时不逐帧刷写；每两秒做一次网络刷新。轮廓颜色继续为青绿色 `0,255,185`，距离继续为 3000。
- 拾取后恢复原始状态，持有期间不强制发光；再次丢弃重新启用。回收只匹配完整实体句柄，实体槽位复用不会继承旧枪状态。
- 地图 HammerID／实体名晚于发枪出现时，可重新识别为地图神器枪，避免旧“服务器发放”标记永久屏蔽它。普通购买/发放枪械及刀不因此全部发光。
- `css_ze_markers_status` 新增 `glowRepairs` 与逐枪实际状态；`glowingGuns` 现在读取真实字段，不再虚报。

这里修复的是枪械轮廓提示，不重建或替换地图自身的剑、翅膀、光柱等神器粒子/模型。按钮鸡仍然按一次消失，下一回合重置。

## 跟随 Steam 工坊更新

新增常驻 `WorkshopUpdateService`，随服务器插件启动，无需额外计划任务或客户端插件：

1. 默认每 **60 秒**检查本专服缓存中已有 VPK 的工坊条目，自动发现后来通过正常换图下载的新条目；不会把候选提名直接变成换图，也不会扫描用户的个人 Steam 游戏库。
2. 向 Steam 官方接口查询 `time_updated`，只接受请求过的有效 CS2 内容。经 Steam GameServer UGC 查询已安装版本；需要更新时调用官方 `DownloadItem`，让 Steam 处理下载及内容完整性。
3. 最多同时发起两个后台下载。请求成功不算完成；必须安装状态正常、没有待更新/下载标志且安装时间戳不旧于远端版本，才显示 `current`。
4. 网络失败、Steam 尚未准备好、下载拒绝会重试；超时记录状态。私有、删除或不可查询条目保留旧文件并显示 `unavailable`，不删除整个缓存，也不把失败当成最新版。
5. **下载自动进行，正在运行的地图不强制重载。** 已加载进内存的实体和脚本不会被文件更新热替换；新内容在下次 RTV／服主授权的地图加载或正常服务器重启时使用。保持用户原有“只有明确重启/结束指令才结束回合”的要求。

仍保留原规则：聊天 `host_workshop_map +ID` 只添加候选；有多个候选时投票选下一张，RTV 必须严格超过 80%；只有服主可以立即换图。自动更新服务不执行 `host_workshop_map`、`changelevel`、结束回合或重启命令。

已安装的工坊服务器资源包也在此缓存内，会同样检查更新。此补丁本身没有新增客户端素材，不要求重新发布 `saibochana_Server`。

配置位于 ZePractice 的 `WorkshopUpdates`；旧配置省略此节时使用以下默认值：

```json
"WorkshopUpdates": {
  "Enabled": true,
  "CheckIntervalSeconds": 60,
  "RetrySeconds": 60,
  "DownloadTimeoutSeconds": 1800,
  "MaximumConcurrentDownloads": 2
}
```

服主／服务器控制台查看当前地图：`css_ze_workshop_update_status 3817448617`。省略 ID 可查看全部条目，控制台单行长度有限时按 ID 查询。状态会报告 `remoteUpdated`、`installedUpdated`、错误、请求次数；`current` 表示磁盘缓存已更新，不等于当前内存中的回合已换成新版本。
