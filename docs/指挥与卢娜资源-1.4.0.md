## 使用方式

画线消退方向按用户后续更正为**由旧到新**；旧版“松开后由新到旧”方案已废止。每段计时从画出开始，不等待松开R。

| 聊天/操作 | 行为 |
|---|---|
| `!leader` | 存活人类CT上/下指挥；无管理员要求，同时1名 |
| `!leader on` / `!leader off` | 明确上/下指挥 |
| `!unleader` | 下指挥，仅取消本人指挥发光；已有点继续计时 |
| 鼠标中键（原生玩家ping） | 放置10秒标点；对准已有点时在原到期时间上加10秒 |
| `!clearpoints` | 当前指挥清空全部标点 |
| 按住R（原生换弹按钮） | 沿准星命中位置画青蓝色线，每段从画出时计时10秒，由旧到新消退，持续按住R时旧线也会到期 |
| `!ze_public` | 菜单中进入上/下指挥和清点功能 |
| `!ze_commander_status` | 指挥、点、线、射线和错误诊断 |
| `!ze_model_status` | 人物模型应用诊断 |

五个点分别为红、绿、蓝、黄、紫。第六个替换最早创建的点，续时不改变创建顺序。离任、死亡、换队、断线不删点；下一任共享这组点，可续时或满5个后替换最早的。清点命令、重开回合、换图、卸载插件会清点。

指挥与标点设置全地图发光范围，并在传输过滤中显式保留；队友隐藏排除当前指挥。实际客户端穿墙轮廓、远距离显示与文本可读性仍需真人验收，不能用服务端字段读回替代画面检查。

R键不重新绑定，保留原换弹动作。画线每0.05秒采样，移动不足4单位不添段；超过1024单位的落点突变断笔，避免穿越地图错误连线。每段独立计时10秒，全局最多384段；松开R或离任只断笔，不重置任何已有线段的计时，也不立即删除线。所有线段无伤害、不作为绊线。
