# 无扩散与地图身份修复 1.3.5

日期：2026-10-13。仅修改服务器插件与跑图专用配置；不修改地图脚本、作者/赞助名单、管理员名单、密码、绑定地址或客户端文件。

## 本次修复

### 个人枪械无扩散

- `!nospread on` 开启、`!nospread off` 关闭，省略参数切换；无需权限，仅 CT 人类可开启。
- 服务端继续按当前持枪者的个人状态拦截 `GetSpread` / `GetInaccuracy`，同时清零后者的输出参数。不开全服无扩散，不改共享武器 VData。
- 新增向本人发送 `weapon_accuracy_nospread` 预测配置：开关立即发送、换 pawn 后重发、每两秒刷新；死亡、T、观察者及换队重置期间恢复 0，换图和卸载也恢复。
- 正常后坐力仍然保留。枪口抬升或连续扫射图案不等同于随机散布；本次没有增加无后坐力功能。
- 新增只读的 `CMsgTEFireBullets` 观察诊断，不修改射击包来掩盖服务器命中结果。
- `predictionSent` 表示已发送配置，**不是客户端确认**。机器人没有个人客户端，因此该值为空；没有真人收件人的测试服可能不产生射击网络包，`shotPackets=0` 不等于没有真实发弹。

### 作者/赞助通道的身份链路

此前 `cs2f_map_steamids_enable` 实际已经是 `true`，但运行服仍为 `sv_lan=true`、服务器身份 `[I:1:0]`。旧日志多次出现 `STEAMAUTH ... failure code 10; ignoring because local connection`。本机 SDK 定义错误码 10 为 `k_EAuthSessionResponseAuthTicketNetworkIdentityFailure`，即票据对应的网络身份与验证票据的服务器不匹配，不能解释成“地图脚本没有运行”。

- 源码和正式跑图专用 `server.cfg` 改为 `sv_lan 0`，保持 `cs2f_map_steamids_enable 1`，不关闭 Steam 认证、不修改绑定地址。
- 新增 `MapIdentityService`，仅当控制器的 SteamID 与 CounterStrikeSharp `AuthorizedSteamID` 完全一致且属于正常个人账号时，向本人 pawn/controller 写入数值身份属性，并发送服务器端 `player_connect.steam_id` 字符串唤醒地图身份适配器。
- 身份以字符串传递，避免 JavaScript 数字精度丢失；出生更换 pawn、换队清理完成、延迟认证和插件重载后补发。槽位、userid、pawn、身份绑定分别校验；机器人、未授权或身份错配均不补发。
- `AuthorizedSteamID` 是 CounterStrikeSharp 依据引擎 `IsClientFullyAuthenticated()` 提供的授权身份；本服务没有独立验证 Steam 票据，也没有把原始 SteamID 当认证结果。
- 不直接授予 `author`、`mapper`、`zanzhu` 等角色，不修改名单或身份过滤器。通道权限仍由地图原有逻辑判断。空服取得有效服务器身份不证明真人票据错误已经消失，也不证明通道已经恢复。
