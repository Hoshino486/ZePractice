# 地图刀、个人无扩散与自动踢人修复（1.3.4）

## 玩家指令

| 聊天指令 | 行为 |
| --- | --- |
| `!nospread on` | 人类 CT 开启自己的枪械无扩散 |
| `!nospread off` | 关闭，恢复该枪械正常散布 |
| `!nospread` | 切换自己的开关 |
| `!ze_nospread on/off` | 同一功能的完整名称；也支持 `1/0` |

无需管理员、付费、练习角色或已认证权限。默认关闭；仅作用于开启者的枪械，不改变其他玩家。全员自助菜单 `!ze_public` 增加相同开关。服务器以持枪者当前阵营为准：变成僵尸或观察者时停止应用，回到人类后恢复本次连接的个人选择；重新连接、换图或重载插件后回到默认关闭。

无扩散去除弹道的随机散布与不精准量，不是无后坐力，也不是自动瞄准。枪口抬升、瞄准方向、弹丸数量、射速和伤害保持原样。不写共享武器 VData，不开全服 `weapon_accuracy_nospread`，不改客户端文件或地图脚本。

## 地图神器刀

`PublicGameplay.AllowZombieMapKnives` 默认 `true`。T 僵尸可拾取并持有地图神器刀，包括未列入 `ZombieKnifeItems` 的刀、模板生成的命名刀、只有 HammerID 的刀。禁枪、禁买枪和非刀类神器限制保留。拾取、装备和库存巡检使用同一规则，不再被旧白名单清理。

这是服务器插件层放行；地图本身的阵营筛选、技能条件仍由地图作者逻辑决定。不修改地图脚本、作者名单、赞助名单或 Steam 身份。如以后确需恢复原严格白名单策略，可显式设置该选项为 `false`。

实际查到旧运行值为 `mp_autokick=true`、`mp_suicide_penalty=true`，截图显示“因自杀次数过多”。当前改为：

```cfg
mp_autokick 0
mp_suicide_penalty 0
```

写入正式 `cfg/ze-practice/server.cfg`、源码配置，并在插件基础规则、每图延迟应用和规则重载中重新应用。`mp_autokick` 同时关闭引擎自带的挂机/队友伤害自动踢人；管理员手动踢人、封禁与其他管理权限不变。已断开的玩家仍需自己重连。
