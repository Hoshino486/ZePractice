# 地图枪发光网络同步 1.3.7

日期：2026-10-13，Asia/Shanghai。

## 本次问题与修正

用户截图中的 SSG08 和地图 P250 已被 1.3.6 识别，服务端返回 `glowing=true`，但画面没有轮廓。因此这些字段不再作为客户端已显示的证明。

现场通过当前引擎 Schema 确认：`CGlowProperty.m_bGlowing` 和 `m_fGlowColor` 不属于网络字段；真正发送给客户端的九个成员是类型、队伍、最大/最小距离、覆盖颜色、闪烁、持续时间、开始时间以及可高亮标记。旧版只调用 `SetStateChanged(entity, "CBaseModelEntity", "m_Glow")`，缺少这些内嵌成员各自的变更通知。

1.3.7 新增 `MapGlowReplication.NotifyChanged`，在启用、修复、两秒刷新、拾取恢复、关闭和卸载时，逐项通知九个网络成员。偏移从运行时 Schema 获取，不把本次观测偏移硬编码到产品里。只修改服务器插件，不创建替身枪，不修改枪的模型、碰撞、神器技能或地图脚本。

`css_ze_markers_status` 新增 `replication: "glow-members-v2"` 和 `visibility: "server-state-only"`。`glowingGuns` 仍是服务端状态计数，不表示客户端视觉验收成功。
