# ZePractice 1.3.2：穿墙、连跳、僵尸武器与切队重置

日期：2026-10-12。适用当前 Windows 专服、CounterStrikeSharp API 1.0.376.0、已安装 CS2Fixes gamedata。

## 玩家行为

- 所有人继续使用 `!ze_join t`、`!ze_join ct`、`!ze_join spec`，不要求权限、不限切队次数。对同一阵营再次使用也会重置角色。
- 换队时撤销个人穿墙，清理旧生命的库存、神器身份及实体名称，等待至少 1.25 秒再出生。快速连续请求以最后一次选择为准；观察者不强制复活。
- 不强行把神器刀丢到地上。换队属于放弃旧角色：不可丢神器刀随旧库存清理，不转交到新阵营，也不生成可重复领取的地面神器。
- T 僵尸只可持普通刀和地图明确配置的僵尸刀，禁止买枪、捡枪、手雷、人类神器刀；切回 CT 后武器权限按当前阵营立即恢复。管理员同样遵守 T 的武器限制。
- T 出生为 35000/35000 血、2500 护甲；回血回甲与上限规则保持。CT 按既有服务器默认出生，不自动回血回甲。
- `!ze_noclip` 对所有玩家开放。开启时阻止地图的 MoveType 写入覆盖个人穿墙；关闭后恢复地图最新要求的移动模式。
- `!ze_bhop on/off` 为个人持空格连跳开关。穿墙期间不计连跳，关闭穿墙并落地后生效；连续第 5 跳仍按默认地速限制水平速度。
- 全服无跳跃疲劳，无须输入指令。默认空速仍为 `sv_airaccelerate 12`、`sv_air_max_wishspeed 30`、`sv_maxvelocity 3500`。

## 神器残留的原因与处理

普通 `CCSPlayerController.Respawn()` 会复用玩家 pawn。只清标签、名字再复活，并不会消除精灵脚本保存的 owner 引用；它仍会每 0.2 秒写旧持有者的移动状态。

正式方案不替换原生 pawn，不修改地图脚本、不伪造重连、不踢玩家：

1. 服务端监听实际神器拾取输出，按完整武器实体名称（含模板实例后缀）记录持有者。
2. 换队/死亡感染时，撤销该持有者的原生 game_ui，并释放其独立神器模型和运动代理。精灵的旧脚本宿主失效后，原有调度不再控制复活玩家。
3. 清理库存与 pawn/controller ResponseContexts、pawn 实体名及 DamageFilter；不改 Steam 昵称。
4. 等待旧生命退出，再执行正常引擎复活，恢复颜色、重力、速度倍率和 WALK。保留原生物理模拟、出生点与地图传送。
5. 复活请求带代次保护，地图更换、手动重启、断线、连续切队和外部原生切队不会让旧回调抢先复活或反向感染。

`PublicGameplay.ArtifactResetRules` 是服务器插件配置，不是地图脚本。当前内置 `ze_forhidden_slicoo_cn` 的精灵、萝莉、法师、老者、黑岩、熊、飞刀及恶魔刀相关独立实体清理规则。只匹配确切名称和数字模板后缀；不使用通配符，不删除 `functions`、`map_brush` 或 point_script 加载器。另一玩家接管同一实例后，原持有者不会再清理它。

其他地图仍清库存、标签、名字、伤害过滤并正常复活；如有同类独立脚本宿主，需在服务器规则中配置该地图的实体名称，不假定所有地图使用同一套神器结构。被放弃的神器不在本插件中自动重生，后续恢复由原地图回合/模板逻辑负责。
