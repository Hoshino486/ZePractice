# ZePractice 1.3.3：全服默认闪光与烟雾免疫

日期：2026-10-12。基于已部署的 1.3.2，只增加服务端免疫，不修改地图脚本或客户端。

## 默认行为

- T 僵尸、CT 人类以及有效观察者 pawn 均受保护，没有管理员、SteamID、个人开关或练习模式限制。
- 加入、复活、死亡感染、切换阵营及插件热重载后自动保持；不需要输入开启指令。
- 闪光清零原生持续时间、白屏强度、致盲开始与结束时间。事件处理之外，在实体模拟后及传输前再次清理，避免本帧后续写入重新带回效果。
- 烟雾弹正常投出、飞行、落地及触发爆炸事件。起烟后抑制烟云网络状态和传输，再在安全的世界更新点删除已引爆投掷物；不删除玩家背包中的手雷或未引爆投掷物。
- 特殊手雷的黑洞与屏障事件继续传递，不关闭已有技能。地图 `info_particle_system`、`env_smokestack` 等独立粒子、剧情雾效和地图脚本不在清理范围。
- 不需要更新 `saibochana_Server` 资源包，不新增客户端文件或游戏全局挂载。

## 实现与状态

新增独立 `GrenadeImmunityService`，使用本机 CounterStrikeSharp 1.0.376 提供的 schema 字段和监听接口，没有新增原生签名、硬编码偏移或客户端命令。原有仅保护部分 CT→T 情形的 `GameplayService.OnBlind` 已移除，避免两个互相依赖模式条件的免疫实现并存。

烟雾跟踪使用完整实体句柄（含 serial）与地图代次，防止延迟回调误删换图后复用同一索引的新实体。已有烟云在热重载时会重新扫描。遇到删除异常保留跟踪并重试，诊断累计记录错误，不静默报告成功。

服务端控制台或 RCON 输入 `css_ze_immunity_status` 查看状态。正常例：

```text
immunity=on flash=blocked smoke=blocked tracked=0 flash_clears=2 smoke_removed=1 errors=0
```

这只是诊断命令，不是开启条件。计数在插件重载后重新开始；未引爆烟雾弹可能使 `tracked` 暂时大于零。
