## 普通玩家操作

所有真人玩家（含观察者）均可参与，不需要管理员权限，角色 Deny 或关闭普通练习权限也不会关闭这些公开命令。

| 聊天输入 | 行为 |
| --- | --- |
| `host_workshop_map +3817448617` | 将此 Workshop ID 加入候选列表；不切图、不自动计入选图票或 RTV |
| `host_workshop_map 3817448617` | 同上，`+` 可省略 |
| `!ze_workshop 3817448617` / `!host_workshop_map 3817448617` | 添加候选的别名 |

| `unrtv` / `!unrtv` | 撤回 RTV；换图倒计时结束前仍可撤回 |

### 两类票各自独立

1. **选图票**：决定下一张图。所有在线真人均有投票权，不强制每人投完；未投票者视为弃权。
2. **RTV 票**：决定是否现在切图。在线真人支持比例必须**严格超过 80%**，不是达到 80%。
3. 只有一个候选时免选图投票，但依然需要 RTV 门槛；多个候选完全无人选图时不会自动随机换图，须先有人选图。
4. 达到门槛时，选择最高票地图；最高票并列才随机抽取其中一张，结果只抽一次。锁定后默认 5 秒倒计时。
5. 倒计时期间暂停新增候选和改选图票。撤回 RTV、玩家加入或断线导致比例不足时取消倒计时，并保留有效选图票；再次满足时重新结算。
6. 断线玩家的选图票和 RTV 会清除；重连/复用槽位不继承旧票。真人观察者计入分母，机器人、HLTV、连接尚未完成者和控制台不计入。
7. 换图清除选图票与 RTV；候选列表保存在磁盘，服务器重启仍保留。单纯手动重开回合不清除投票。

| 在线真人 | 最少 RTV |
| --- | --- |
| 1 | 1 |
| 2 | 2 |
| 4 | 4 |
| 5 | 5（4/5 恰好 80%，不够） |
| 6 | 5 |
| 10 | 9 |
| 20 | 17 |

算法为 `floor(4 × 在线真人数 / 5) + 1`。无人在线时永不形成有效 RTV。

## 服主立即换图

即时换图硬限制为：服务端控制台 / RCON，或插件配置 `OwnerSteamIds` 中、Steam 身份已认证的服主。仅有普通管理员角色、`*`、CSS `@css/root` 或可信本机连接，不足以使用这些即时换图入口。已配置服主仍拥有本插件全部权限，原管理员名单保持原样。

| 聊天命令 | 行为 |
| --- | --- |
| `!ze_workshop_now 3817448617` | 立即请求 Workshop 地图，不等待投票 |
| `!ze_installed_maps [关键词]` | 服主专用的已安装地图列表，确认后立即换图 |
| `!ze_map ze_forhidden_slicoo_cn` | 立即切换已安装地图；已关联 Workshop ID 时保留 Workshop 加载路径 |
| `!ze_map_remove 3817448617` | 删除持久候选及该候选选图票 |

控制台把 `!` 替换为 `css_`。引擎服务端控制台 / RCON 的 `host_workshop_map ID` 仍是服主级立即加载；**聊天框中的同名文本才是候选提交**。服主聊天输入普通 `host_workshop_map +ID` 也只添加候选，避免误切图。

原生 `cs2f_votemanager_enable` 固定为 `0`，阻止 CS2Fixes 旧 60% RTV、原生 `!map` / `c_map` 与 `setnextmap` 投票路径绕过本规则。使用本插件的新入口；其他 CS2Fixes 管理/辅助功能不整体关闭。

## 地图按钮的绿色鸡

- 对象是地图实体 `func_button`、`func_rot_button`、`momentary_rot_button`，不是主菜单、投票列表或 HUD 按钮。
- 使用游戏内置鸡模型 `models/chicken/chicken.vmdl` 的装饰性动态实体，不生成有 AI 的真实鸡。
- 鸡模型包围盒中心对准按钮碰撞包围盒的世界坐标中心，考虑按钮角度，跟随按钮移动和旋转。
- 绿色轮廓 `RGB 40,255,65`，所有阵营可见，默认范围 3000 个 Source 单位。
- 标记无实体碰撞、不受普通伤害，不重写按钮的输入输出、冷却或地图触发逻辑。
- 1.3.1 起，按钮首次成功触发 `OnPressed` 后只删除该按钮的鸡；本回合的周期扫描不会再次生成。锁定按钮的尝试使用、伤害、松开不算成功触发。
- 新回合恢复按钮标记；新生成按钮会补标，实体句柄包含序列号，索引复用不会误伤新按钮。按钮/标记销毁、换图与插件卸载均处理对应状态。每图默认最多 1024 个按钮标记。

## 地图枪的青绿色提示

- 使用原枪模型的原生发光轮廓，颜色 `RGB 0,255,185`，不是额外菜单图标。
- 有 Hammer ID / 实体名的地图枪，以及开图时地图自带的无主枪被识别；普通玩家领取的枪不标记，刀和非枪械不纳入。
- 地图枪无主时显示，拾取后恢复地图原有 Glow 状态，防止持枪时暴露隐藏玩家；再次落地重新显示。
- 保存并恢复原颜色、类型、队伍、范围和时间属性，不开启与 CounterStrikeSharp 冲突的原生 EntWatch。
