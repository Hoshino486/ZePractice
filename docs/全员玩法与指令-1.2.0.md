## 启动与入口

- 正式启动：`E:\mapper\chana\ZePractice\run.bat`。
- 聊天输入 `!ze_public` 打开全员自助菜单；已有 F9/Z 数字主菜单继续保留。
- 下列命令不需要管理员、角色授权或练习模式。聊天使用 `!`，客户端控制台使用 `css_` 前缀，例如 `css_ze_hp 12000`。

## 全员聊天指令

| 指令 | 参数与行为 |
|---|---|
| `!ze_public` | 打开全员自助菜单 |
| `!ze_hp 12000` | 设置自己的当前生命和本次生命上限；范围 1–35000，超限拒绝 |
| `!ze_armor 500` | 仅 CT 设置自己的当前护甲；范围 0–2500；T 护甲交由服务器管理 |
| `!ze_noclip` | 开关个人穿墙，需要存活；死亡/新生/换队后关闭 |
| `!ze_ammo on` / `!ze_ammo off` | 开关免换弹；开启持续补满当前武器弹匣，关闭正常换弹 |
| `!ze_bhop on` / `!ze_bhop off` | 开关按住空格连续跳跃；省略参数也可切换 |
| `!ze_music 0.3` | 个人地图声源音量比例 0–1；0 静音、1 原始音量，不改其他玩家音量 |
| `!ze_hide 999` | 隐藏 999 游戏单位以内的存活队友模型及武器，保留姓名；范围外正常显示 |
| `!ze_hide 0` | 关闭队友模型屏蔽；参数仅接受 0–999 |
| `!ze_join t` / `!ze_join ct` / `!ze_join spec` | 自己切到僵尸、人类、观察者；普通入队路径同样补齐复活 |
| `!ze_roundtime 30` | 本地图回合时间设为 30 分钟并重设当前倒计时；范围 1–180 分钟 |
| `!ze_restart` | 请求约 1 秒后重开当前回合 |
| `!ze_endround` | 主动结束当前回合并进入下一回合 |
| `host_workshop_map 3817448617` | 直接在普通聊天输入，无需 `!`；仅一个数字 Workshop ID |
| `host_workshop_map +3817448617` | 同样接受 ID 前的 `+`，不是将加号作为命令拼接符 |
| `!ze_workshop 3817448617` | 换图别名；也支持 `!host_workshop_map 3817448617` |
| `!ze_public_status` | 查看本人设置；服务器控制台执行 `css_ze_public_status` 查看全部诊断 |

生命、穿墙、护甲需要存活的 T/CT 实体；观察者可以预先设置音乐、隐藏、弹药和连跳开关。数值不接受负数、溢出、命令拼接或超服务器上限。

## 生命、护甲与重生

- **T 一律为僵尸**：出生、CT 死后转 T、主动换 T 和其他插件改变为 T 都初始化为 35000 当前/最大生命、2500 护甲上限。
- `!ze_hp` 同时改变该次生命的当前值和回血上限，最高 35000；下次出生或换队重新使用默认值。T 没有个人调甲指令。
- 默认最后一次受伤后 **5 秒**开始恢复；每秒恢复 **1750 生命、125 护甲**，分别封顶个人生命上限和服务器护甲上限。继续受伤会重算冷却，死亡时不回血。
- CT 不自动回血/回甲。CT 出生遵循普通生命值和服务器普通发甲配置，T 转 CT 不携带 2500 僵尸护甲。
- CT 死亡转 T 并自动复活，T 死亡后保持 T 复活；切观察者不自动拉回战斗阵营。

## 资源、碰撞与地上枪械

- 所有人的金钱不足时补回 **99999**；普通枪械备弹维持 **99**，与个人免换弹开关分开。
- 本次将“弹夹 99”解释为 **备用弹药计数 99**，不是每把枪弹匣容量 99，也不是 99 个完整弹匣。AK 等实际弹匣容量保持武器默认值。
- 免换弹关闭时弹匣会正常消耗，需要正常换弹；开启时弹匣补满。特殊地图枪械容量由武器本身决定。
- 全服人物无相互碰撞，不依赖玩家自己设置隐藏范围。
- 普通玩家枪械连续落地、无人持有满 **60 秒**后删除；拾取会重置计时。
- 不处理刀、手雷及非枪械；有 HammerID、实体名称或地图初始生成标记的枪械保留。地图逻辑运行时生成的无主枪也保守保留，以免删除地图道具。
- 生命/金钱维护约 0.1 秒一次；普通枪械清理约每秒扫描一次，因此删除通常发生在满 60 秒后的下一次扫描。

## 回合与换图

- 加入服务器、死亡、全员被感染、某一队无人、换队以及计时结束，均不自动结束或重开回合。
- 首次地图初始化仍由引擎创建初始回合；之后使用 `!ze_restart` 或 `!ze_endround` 明确推进。
- `!ze_roundtime` 在当前地图手动重开后保留，换地图恢复该地图默认值；倒计时到 0 也不自动结束。
- 1.3.0 的普通 Workshop 聊天指令只加入持久候选；`!ze_maps` 选图，`rtv` 严格超过80%才请求换图。即时切图仅服主 `!ze_workshop_now ID`；实际下载结果以引擎日志为准。
- 换图指令不改写 `server-settings.json` 的默认启动地图。此文件仍保存原启动地图、监听配置与密码。

## 隐藏、音乐与连跳

- 隐藏只影响本人看到的同队存活模型、手持武器；敌人、自己、范围外队友不受影响。姓名用独立 `point_worldtext` 实体保留。
- 音乐通过地图声源 SOS 消息按接收者调节，保留地图原始音量比例；枪声、脚步和玩家语音不是调节对象。特殊地图自定义音频路径仍需逐图确认。
- 连跳默认关闭，开启后按住空格；第 1–4 次连续起跳不施加此功能的水平速度上限，第 5 次起跳限制到正常地速（不高于 250，持枪地速更低时遵循武器），落地后开始下一组。
- 落地停留约 0.25 秒会清掉连续计数。1.3.1 起恢复本机引擎默认空速：`sv_airaccelerate 12`、`sv_air_max_wishspeed 30`、`sv_maxvelocity 3500`；不再使用超高空速。
- 全服常驻无跳跃疲劳，无需指令，也不依赖个人连跳开关：`sv_staminamax`、`sv_staminajumpcost`、`sv_staminalandcost`、`sv_jump_spam_penalty_time` 均为 0。插件每秒维护，换图及重载配置后仍生效；原先要求的第 5 跳水平限速保留，这是独立规则而非疲劳。
- 音乐、隐藏、弹药、连跳在同一次地图连接内保留；换图或重新连接恢复默认，个人生命上限按每次出生重置。
